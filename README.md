# Telco Customer Churn Analysis

## Project Overview

This project analyzes customer churn using Python and Pandas.

The objective is to understand customer behavior, identify patterns associated with churn, and generate business recommendations that can help improve customer retention.

## Dataset

The dataset contains 7,043 customer records and 21 columns covering:

- Customer demographics
- Tenure
- Phone services
- Internet services
- Online services
- Contract information
- Payment methods
- Monthly charges
- Total charges
- Churn status

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / VS Code

## Analysis Performed

- Dataset structure and data types
- Missing-value analysis
- Numerical statistics
- Churn distribution
- Churn by contract type
- Churn by internet service
- Churn by payment method
- Churn by tenure
- Churn by monthly charges
- Churn by customer characteristics
- Service-level churn analysis
- Data visualizations
- Business insights and recommendations

## Key Business Objective

Identify customer segments with higher churn risk and provide actionable recommendations for improving customer retention.

## Conclusion

The analysis demonstrates how exploratory data analysis can be used to identify churn patterns and support data-driven customer retention strategies.
